# Cairn GTM website

Production static site for https://cairngtm.com.

## Local preview

Run any static server from this directory, for example:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Deployment

Designed for Vercel as a zero-build static site. `vercel.json` contains lightweight security headers and clean URL settings.

## Primary destinations

- Pipeline Analyzer: https://cairn-pipeline-analyzer.vercel.app/
- Pipeline Calculator: https://patrickarvia.github.io/cairn-pipeline-calculator/
- Writing: https://patrickarvia.substack.com/
